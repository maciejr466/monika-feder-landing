# MoniSpeech Landing Page

Stwórz nowoczesny, elegancki, jednostronicowy landing page w języku polskim dla gabinetu "Monika Feder – Neurologopeda dla dzieci i dorosłych". Strona ma budzić zaufanie, być ciepła, profesjonalna i skupiona na konwersji (umówienie wizyty telefonicznie).

## MARKA I STYL
- Styl: czysty, medyczny, premium, ale ciepły i przyjazny rodzicom. Dużo białej przestrzeni, delikatne zaokrąglenia, subtelne cienie.
- Paleta kolorów: ciepły grafit (#3F3F46) jako kolor tekstu, złoto/szampan (#A8894A, akcent #C9A961) jako kolor akcentowy i przyciski, kremowa biel (#FAF8F4) jako tło sekcji, biel (#FFFFFF) jako tło kart. Dodatkowo bardzo delikatny pastelowy błękit lub miętę jako tło wybranych sekcji.
- Typografia: nagłówki w eleganckim sans-serif lub serifie (np. "Playfair Display" lub "DM Serif Display"), tekst w "Lato" lub "Inter".
- Animacje: delikatne fade-in przy przewijaniu, hover na kartach i przyciskach. Bez przesady.
- W pełni responsywna, najpierw mobile (większość rodziców wejdzie z telefonu).

## DODATKI
- Na mobile pływający przycisk połączenia (sticky "Zadzwoń") na dole ekranu.
- Dane strukturalne schema.org (LocalBusiness / MedicalBusiness) z adresem, telefonem i oceną 4,8.
- SEO: title "Neurologopeda Zalasewo – Monika Feder | Dzieci i dorośli", meta description z frazami: neurologopeda Zalasewo, logopeda Poznań okolice, terapia miofunkcjonalna, frenotomia.
- Dostępność: kontrast zgodny z WCAG, czytelne rozmiary czcionek, aria-labele.
- Cały tekst po polsku, ton: spokojny, empatyczny, ekspercki, bez przesadnych obietnic wyleczenia.
- Używaj React + Tailwind + shadcn/ui, komponenty podziel na osobne pliki.
